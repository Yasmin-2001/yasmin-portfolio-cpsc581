# Yasmin Semsar Portfolio

Complete static website source for the final portfolio design.

## Files
- index.html: portfolio content and sections
- style.css: layout and responsive styles
- cats.js: interactive cat room, feeding, toys, and animations
- assets/: project screenshots and images
- documents/: final Project 2 and Project 3 reports

## Run locally
Open index.html in a browser, or serve this folder:

    python -m http.server 8000

Then open http://localhost:8000.
No npm installation or build step is needed.

## GitHub Pages
Upload the extracted files to your repository, with index.html at its root.
In repository Settings > Pages, choose Deploy from a branch, select main
and / (root), then save. Keep assets/ and documents/ alongside index.html.
Upload the extracted contents, not just this ZIP.
